# PromptGPT Frontend

The frontend for PromptGPT ― a ChatGPT style frontend with a prompt-presets support added.

Coupled with a serverless REST API, from pgpt-backend-lambda repo.

## Technologies

- **CI/CD** GitHub Actions for AWS S3
- **Vite**, **React**, **TypeScript** for the frontend
- **Vitest** for testing
- **ESLint**, **Prettier** for code quality
